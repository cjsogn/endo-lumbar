# Data Access

The analyses in this repository use patient-level data from the Norwegian Registry
for Spine Surgery (NORspine). Due to data protection regulations, individual patient
data cannot be shared publicly.

## How to access the data

Data can be requested through the NORspine application process:
- Contact: NORspine registry (https://www.kvalitetsregistre.no/registers/norsk-ryggkirurgiregister)
- The application must be approved by the Regional Committee for Medical and Health
  Research Ethics and the institutional data protection officer

## Data files used in the analysis

- `df_disc_full.csv`: Full analysis dataset (disc herniation cohort, N=421)
- `df_disc_12m.csv`: 12-month eligible subset (N=254)
- `df_disc_imp.rds`: Imputed dataset (R format)

These files are generated by `scripts/analysis/01_data_preparation.R` from the
original NORspine SPSS export.
